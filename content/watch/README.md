# 观察 · 内容件（每天一个文件）

## 怎么发一期（三步）

```bash
# 1. 写内容
cp content/watch/_模板.md content/watch/2026-11-09.md   # 改期号/日期/条目

# 2. 构建（生成页面 ＋ 重排首页与列表 ＋ 自动取读数）
python3 build/watch_build.py 2026-11-09

# 3. 盖日期 ＋ 推送
python3 build/stamp.py
git add -A && git commit -m "观察 No.2 · 2026-11-09" && git push
```

## 文件格式

```
期号: 2
日期: 2026-11-09
标签: 监管 · 技术 · 商业
摘要: 一句话，出现在首页与列表页
（空行）
## 【主标签】判词
· 发生了什么：……
· 这意味着什么：……
· 所以要关注什么：……
来源：<机构> <日期> <链接> 〔角标〕〔层级〕

## 【主标签】判词
……
## ★ 今天没搞懂的
……
```

### 硬规矩

| 规矩 | 说明 |
|---|---|
| **判词三条** | ⛔ 不用否定式 ／ 要有「谁→换到什么」的对应关系 ／ 带一个可核的东西 |
| **三拍** | 发生了什么／这意味着什么／所以要关注什么，**缺一段就不发** |
| **主标签** | 只用六个：编辑部内部 · 读者端 · 技术供给 · 商业模式 · 监管与政策 · 中国本土 vs 海外 |
| **标签分散** | 一期里全挤同一个侧面＝视野窄 |
| **条数** | 3–5 条；标不出角标的就不入选 |
| **来源分层** | 〔一手·英文〕〔一手·中文〕〔二手〕；只有中文二手源的料，**本期不选** |

## 读数不用手抄

`build/watch_build.py` 自动从
`素材库/materials/收割机/3_报告/收割机日常报告_<YYYYMMDD>_*.json`
取 `fetch.newsnow.total / new / rate / sources` 与 `store.atoms` 写进刊头。
取不到就写「读数未取」，**⛔ 不编数**。
