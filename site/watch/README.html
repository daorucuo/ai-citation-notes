### 硬规矩

| 规矩 | 说明 | |---|---| | 判词三条 | ⛔ 不用否定式 ／ 要有「谁→换到什么」的对应关系 ／ 带一个可核的东西 | | 三拍 | 发生了什么／这意味着什么／所以要关注什么，缺一段就不发 | | 主标签 | 只用六个：编辑部内部 · 读者端 · 技术供给 · 商业模式 · 监管与政策 · 中国本土 vs 海外 | | 标签分散 | 一期里全挤同一个侧面＝视野窄 | | 条数 | 3–5 条；标不出角标的就不入选 | | 来源分层 | 〔一手·英文〕〔一手·中文〕〔二手〕；只有中文二手源的料，本期不选 |

读数不用手抄

build/watch_build.py 自动从 素材库/materials/收割机/3_报告/收割机日常报告_<YYYYMMDD>_*.json 取 fetch.newsnow.total / new / rate / sources 与 store.atoms 写进刊头。 取不到就写「读数未取」，⛔ 不编数。

这个栏目怎么运作
每天扫公开源，挑 3–5 条值得重点看的，一条一条单独写，不做配对。
每条三段：发生了什么 ／ 这意味着什么 ／ 所以要关注什么。缺一段就不发。
收料标准：〔双源〕〔有数〕〔第一次〕〔冲突〕〔落位〕。
来源分层：〔一手·英文〕〔一手·中文〕〔二手〕—— 只有中文二手源的料，本期不选。
语言：不设分站，中文为主；哪条的一手是英文、英文更准，就直接用英文写。
