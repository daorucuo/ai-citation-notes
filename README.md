## 我们的判断（八条）

读完之后，我们自己的结论：

1. **这件事值得做。** 零点击成为常态，AI 摘要正在改变用户行为与网站流量结构。
2. **"对题"比"权威"重要。** 与引用影响力相关性最高的是内容与问题的匹配度，高于内容质量本身。
3. **"被引用"和"被当作来源"是两件事。** 引用广度与吸收深度必须分开测量。
4. **内容形态决定命运。** 能被切出定义、数值事实、对比、操作步骤的内容，更容易被引用。
5. **测一次不作数。** 可见性评估需要重复试验与结构感知指标。
6. **"引来错版本"是真实风险。** 模型同时检索到新旧两版信息时，回答会不稳定。
7. **合规做法可行。** 白帽优化有效，模型侧对操纵手段的抗性在增强，捷径窗口在收窄。
8. **底座与平台是两层。** 把检索与推理解耦，做与厂商无关的可信来源层，才谈得上"基础设施"。
